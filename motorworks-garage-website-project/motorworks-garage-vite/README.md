# MotorWorks Garage — Website Concept

A responsive auto repair and maintenance website concept built with React and Vite. The public-facing brand is **MotorWorks Garage**; the word Vite is only part of the development setup and is not used in the website name or page title.

## Features
- Responsive desktop and mobile layout
- Service cards, about section, process steps, and contact details
- Mobile navigation
- Demo appointment form with client-side confirmation only
- Accessible labels and basic SEO metadata

## Run locally
1. Install Node.js.
2. Open this project folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev` and open the local URL shown.
5. Run `npm run build` to create the production build in `dist`.

## Deploy to Vercel
1. Upload the contents of this project folder to a new GitHub repository. Ensure `package.json`, `index.html`, `vite.config.js`, and `src/` are at the repository root.
2. Import that repository into Vercel.
3. Framework preset: **Vite** (or let Vercel detect it).
4. Build command: `npm run build`.
5. Output directory: `dist`.
6. Deploy.

## Before using for a real business
This is a portfolio demo. Replace the fictional phone/address and sample copy with verified business details. The contact form does not send or store submissions; connect a form backend or booking provider before launch. Images load from Unsplash and require an internet connection.
